# Perfume Rater
Веб-сервис для выбора парфюма
Пользователь ставит ароматам оценки от 1 до 10, а модель предсказывает,
какую оценку он поставил бы ароматам, которые ещё не пробовал
(по аналогии с сайтом Criticker). 

## Стек

Python 3.12, FastAPI, Jinja2, HTMX, SQLite + SQLAlchemy 2.0,
pandas / numpy / scikit-learn, Plotly, pytest.
